# 版式、颜色、符号与数字

排版是「公司课题研究」的表面标准，只为这项研究服务。本文件是排版规则的唯一写入处，不要再另维护一份平行的排版技能或另一份颜色说明。以后若有其他目的的排版，再单独立一份。

排版规则若有歧义，以课题研究报告成品的图表配色、标注方式和验收门禁为准；成品里的文字重叠、截断、横轴拥挤、表格过密等低级错误，不能当作规范。

## 页面

- 决策简报默认 A3 横版，白底黑字，可打印。HTML 是母版，用 headless Chrome 导出 PDF。用户另行指定时，才改用其他幅面（例如 A4 纵版长稿）。
- 每页都有页眉（部分名｜节名）、页脚（来源）和页码。
- 同类页的卡片等宽等高，左右栏顶底对齐，上文下图比例全篇一致。
- **不缩字号**。版面挤时，改写句子、调整间距或分页；版面空时，调整间距填满，不堆字。只有用户对某一页明确同意，才可以在那一页缩字，交付说明里要写明。
- 不留孤行（末行只剩一两个字）：改写句子消除，不靠缩字。
- 附件网址用纯文本，不做超链接，不得溢出或撞列。
- 单页自足：每页单独看都能理解，不得用「见第几页」代替必要解释。删重时不得删掉口径、时点、对比区间。

## 低级错误（绝对不能犯）

### 结构性门禁

1. 文字重叠、压柱、压线、裁切、看不到。
2. 内容被切断：页尾断句、断词。
3. 表格拆页、表头孤立。
4. 半空页、大片异常空白。
5. 内部档案名/本机路径泄露：`资料包/`、`原始档案`、CSV/ZIP 文件名、`/Users/`、`Codex`、`grok`、`00_索引` 等内部代号一律不得出现在读者可见的正文/图注。
6. 繁体字残留（正文非 URL 部分）。
7. 文字越界（左右越界、压页脚）。
8. 孤立标题（页底只留标题、正文在下一页）。
9. 页码漂移（目录页码与实际页码不符）。

### 可读性门禁

10. 裸数字标注：图内数字无时点、无单位、无口径，读者无法理解它指什么（如孤零零的「82.25」「7.89」）。
11. 标注重叠：文字与线、柱、其他文字重叠。
12. 图例缺失：多色系列无图例说明。
13. 颜色词与图内实际线/柱颜色不符（图上黑色柱却写「蓝」，图上蓝色线却写「黑」）——写图下说明时必须逐一核对颜色。

## 图表

1. 高密度复合图（如四层图）：图内只留序号（①②③④）+ 图形，详细说明（图例、口径、关键数字序列）统一放到图下方的说明区，不得硬塞进拥挤的图内。
2. 数据标注必须自带时点 + 口径 + 对比区间（例：「短期消费贷 2020.01 7.89 → 2024.01 峰 10.41 → 2026.09 8.53，▼17.99%」），不得只写一个数字。
3. 图下说明区的颜色词必须与图内实际线/柱颜色逐一核对：住户贷款/个贷（深灰黑）写「黑」、消费贷（深绿）写「深绿」、房贷（深棕）写「深棕」；方向色图增=蓝、减=红。不得沿用已废弃的旧文案（「③层蓝线、消费贷深蓝」）。
4. 柱顶标注配合年份刻度（柱对应年份，柱顶数字即该年值），柱中心对齐刻度，不得错位到年末。横轴必须覆盖观察窗和脚注写到的全部时点，不得在 2016 年截断却标注 2022—2026 的点。
5. 图题、图注不得与图内文字重复。
6. 改颜色词这类共用词时不得全局替换（会误伤相邻层的正确描述），要按层分别处理。
7. 案例页的版面规则（两框对称、图最多占半页）见 `case-page-writing.md`。

## 颜色（评价色与图表色分开）

### 评价色（仅用于借鉴条目、评价标注，不用于图表系列）

| 用途 | 颜色 |
|---|---|
| 好／改善／值得借鉴 | 绿 `#1E8E4E` |
| 接近坏／预警／自查要点 | 黄 `#9A6700` |
| 坏／恶化／避免踩坑 | 红 `#C62828` |
| 引用号 [n] | 紫色斜体 `#5b3fd0`，约 0.8em（唯一例外） |

- 评价性文字其余一律黑色，强调用黑色粗体。标题、对象名、栏目名、中性指标词（余额、新增等）不用评价色。
- 评价色按「结果对被描述对象是好还是坏」来定，不看数字的方向。
- 用户没有点名的语义色和符号，不得擅自改；拿不准时对照上一版保持原样。

### 图表：方向色（锁定，专属「增/减」）

1. 增（正增长）= 蓝色 `#1565c0`，减（负增长/减少）= 红色 `#c0272d`。
2. 蓝、红锁定给「增/减」后，其他指标图（余额、个贷、房贷、消费贷、经营贷）一律不得再用蓝、红——否则读者会把「余额的蓝」误当成「增长的蓝」。

### 图表：指标色（跨地区、跨图、跨层统一，避开蓝红）

1. 住户贷款/个贷（总量）= 深灰黑 `#26313D`。
2. 消费贷 = 深绿 `#238B57`。
3. 房贷 = 深棕 `#6b4f1d`。不得与个贷共用黑色。
4. 经营贷 = 琥珀橙 `#C58A00`。
5. 同一指标跨地区、跨图、跨层（③余额 / ④新增）颜色必须一致。

### 关键判定：方向色 vs 指标色

1. **单系列增减图**（一张图只讲一个指标的增减，如「短期消费贷新增」柱状图，或余额图下方的净变化柱）→ 用方向色：增长柱 = 蓝、减少柱 = 红。
2. **多系列指标图**（一张图讲多个指标的余额/新增，如四层图③④层）→ 用指标色：每个指标一个非蓝红色（消费贷绿、房贷棕、个贷深灰黑），负增长用红。
3. 判定依据：看这张图是「一个指标的增减」还是「多个指标的对比」。前者用方向色，后者用指标色。改颜色前必须先分清，不得一刀切。
4. 废止旧规则「图表用黑色实线、虚线和标记区分系列；柱子只按评价上色」。

### 改色后的强制核对清单

改任何图形颜色（fill/stroke 十六进制色值）后，必须同步核对以下三类文字的颜色词，逐一对应图形实际线/柱颜色：

1. 图下说明区的「X=」颜色词（如「黑=住户贷款」「深绿=消费贷」）。
2. 图内嵌图例「■ X」的 fill 颜色（色块）。
3. 图内数据标注的 fill 颜色。

只改图形色值、不改文字颜色词，是「颜色词与线柱颜色不符」的直接来源。改色 = 改图形 + 改文字，只做一半必错。

### 股价涨跌（如涉及）

1. 涨 = 红色、跌 = 绿色（中国股市惯例，与欧美相反）。

## 三角形与箭头

- **▲▼只表示变化幅度**：数字本身就是变化量或变化率，要写明比较的两个时点。三角只有红、绿两色；紧跟在三角后的幅度数字和三角同色。
- **水平值用「A→B」**：两个数字都是黑色，字重一致，只有箭头按好坏上红色或绿色。终点值前面不放三角。
- 纯属研究对象本身的中性升降，不画三角，用黑字写「下降约 X%」。日期区间用「至」或「–」。
- 每页图例统一写：「▲▼＝变化幅度　→＝由 A 变到 B　红＝恶化　绿＝改善」。
- 先确认 PDF 字体能渲染这些符号。

## 币种与数字

- 默认 ¥（人民币）。正文和汇总用读者的币种（第 1 页的金额要写明币种名）；附件保留原币，方便对原表核对；折算方法和汇率来源写在口径附件里。已经写了读者币种的，就不再并列原币。
- 折算用事件所属期间的官方平均汇率，只用来感知量级；折算年份不同的数不相除。外币图轴不强行换算。
- 金额不带不必要的小数位；比例默认保留一位小数；附件可以写精确值。
- 币别永远写明；幅度要说清是百分比还是百分点。

## 指向与引用

- 关键事实就地写清，不用「见第 N 页」代替。
- 指向附件用【附件 X（第 N 页）】；附件分页时写「第 N–M 页」。改了页数，所有页码引用、第 1 页页码地图和每页页码要一起改。
- 计算只放附件，正文只写结果。

## 唯一最终版

- 正文、页脚、图例里都不放「新增」徽标、「更新」「本次补充」「较上版」或版本号。统计含义的「新增」要保留。
- 草稿阶段可以写「待补」，文件名可以带版本号；用户宣布定稿时全部清掉。

## 附件一致

- 所有附录和来源附件页（包括新增材料的附件）的字号、字重都与主附录保持一致，例如正文常规体、首列加粗，不要整页加粗或放大。

## 技术规则（防断句/拆页）

1. 段落不拆页：`p{break-inside:avoid; page-break-inside:avoid}`。
2. 表格行不拆页：`tbody tr{break-inside:avoid}`。
3. 防断词：用 U+2060 不换行连接符（生成器转为 `&#8288;`）。
4. 标题不孤立：`h1-h4{break-after:avoid; page-break-after:avoid}`。

## 验收

生成或修改报告后，必须跑完下列脚本，全部通过才可交付：

1. `python3 "$SKILL_ROOT/scripts/pdf_audit.py" 报告.pdf [禁用词…]` —— 文字靠边或越界、孤行、占位符、禁用词、页边墨迹。
2. `python3 "$SKILL_ROOT/scripts/终版排版验收.py" 报告.pdf [附录页码.json] [--expect-pages N]` —— 结构性门禁。只有报告已约定总页数时才加 `--expect-pages`；未指定则只报告实际页数，不因此 FAIL。
3. `python3 "$SKILL_ROOT/scripts/检测裸数字.py" <SVG目录>` —— 图内裸数字标注。

脚本不查文字重叠时，重叠要靠逐页看图。门禁 PASS 后仍有疑点，按「读者能否看懂」逐图逐字目检。已知可接受的遗留警告，要在交付说明里逐条列出。
