# report-layout-standard（指向说明）

本仓库曾是独立的研究报告「排版规范」。自 2026-11-19 起，排版已并入技能「公司课题研究」，不再作为平行标准单独维护。

- 唯一完整技能（框架 + 排版 + 验收脚本）在私有仓库：[company-research-skill](https://github.com/99dj464r56-cloud/company-research-skill)
- 本仓库保持公开，只保留排版细则与验收脚本的公开副本，便于查阅；内容与唯一技能中的对应文件同步。
- 写研究报告时，请加载「公司课题研究」，不要再把本仓库当作另一套排版技能来用。
- 验收脚本：`scripts/终版排版验收.py`（可用 `--expect-pages N`，未指定则不因页数 FAIL）、`scripts/检测裸数字.py`。

更新只发生在「公司课题研究」；本仓库是公开镜像指针，不是第二份权威。
